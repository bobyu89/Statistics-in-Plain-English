## 本章在說什麼

單因子變異數分析(one-way ANOVA)用來比較兩組以上在同一連續依變項上的平均數。兩組時它與獨立樣本 t 檢定結論相同(F 是 t 的平方),但三組以上若做多次 t 檢定,型一錯誤的機會會累積,所以改用 ANOVA。核心是把總變異拆成組間與組內(誤差)兩塊:先算平方和,除以自由度得均方,兩個均方相除即 F 值,再查表判斷顯著性。F 顯著只代表至少有兩組不同,還要用 Tukey HSD 等事後比較或事前比較找出差異所在,並以 η² 說明分組解釋了多少變異。

## 何時用單因子 ANOVA、為何不做多次 t 檢定

- 需要一個類別(名義)自變項把人分成至少兩個獨立組別,以及一個連續依變項,例如三種洋芋片口味的 1–7 分喜好評分。
- 只比兩組時 t 檢定與 ANOVA 結論一致,F 值就是 t 值的平方,所以研究者通常在三組以上才改用 ANOVA。
- 三組兩兩做 t 檢定要下三次顯著性判斷,每次都帶一點犯錯機率,次數越多型一錯誤越容易發生;ANOVA 會把比較的組數納入調整。

## 拆解變異:平方和、均方與 F 值

- 個別分數與所屬組平均數的差距視為隨機誤差(組內);各組平均數與總平均數的差距則是組間離差,兩者相加等於個別分數到總平均數的總離差。
- 誤差平方和 SSe 是各組內離差平方的加總;組間平方和 SSb 是各組平均數與總平均數差的平方乘上該組人數後加總;SST = SSb + SSe。
- 平方和要除以自由度才能公平比較:組間自由度 K − 1、誤差自由度 N − K,得到 MSb 與 MSe,再相除得 F。
- F 與 t 的邏輯相同:分子是組平均數之間的平均差異,分母是組內平均變異,只是都改用平方的形式。
- 查 F 分布表(附錄 C)需要組間與誤差兩個自由度;觀察到的 F 大於臨界值,才判定各組平均數有顯著差異。

## 事後比較與事前比較

- 顯著的 F 只說明至少有兩組平均數不同,沒有指出是哪幾組,必須再做事後比較逐對檢查。
- 各種事後比較都是兩組平均數相減再除以標準誤,差別在標準誤怎麼算、嚴格或寬鬆;本書只示範 Tukey HSD。
- Tukey HSD 的標準誤為 √(MSe / ng),結果對照學生化全距統計量的臨界值(附錄 D,依組數與誤差自由度查表)。
- Tukey HSD 假設各組人數相同,組別人數不等時就不是最理想的事後比較方法。
- 事前比較是依研究假設事先規劃的對比,可把幾組合併後再比,例如把兩個美國城市合併與兩個歐洲城市比披薩喜好。

## 效應量 η² 與 SPSS 報表

- 除了 d 之外,另一種效應量是依變項變異中被自變項解釋的比例,即 η²,概念上與決定係數 r² 相同。
- 虛構的藥物實驗:75 名三年級生分成大劑量、小劑量、安慰劑三組,學習興趣平均為 2.76、3.60、2.60。
- 報表中組間 MS = 7.213(df = 2)、誤差 MS = 1.341(df = 72),F = 5.379、p = .007、η² = .130,分組解釋 13% 的變異。
- Tukey 結果:小劑量組顯著高於大劑量組(p = .033)與安慰劑組(p = .009),後兩組之間沒有差異。

## 手算範例與總結

- 以 5、8、12 歲三組各 5 人對泡泡糖口味冰淇淋的喜好為例,依九個步驟從組平均數一路算到 F 值並查表。
- 作者提醒本章只是最基本的模型,真實研究各組人數常不相等,計算會更複雜,需要另外閱讀進階教材。
- ANOVA 串起前面章節:離差平方和來自變異數、組平均數比較類似 t 檢定、η² 則呼應共享變異與效應量的概念。

## 公式

- **F 值**:`F = MSb / MSe` — 組間均方除以誤差均方(組內均方)
- **誤差平方和**:`SSe = Σ(X − X̄₁)² + Σ(X − X̄₂)² + … + Σ(X − X̄_k)²` — 各組內個別值與該組平均數的離差平方,全部加總
- **組間平方和**:`SSb = Σ[ n (X̄ − X̄_T)² ]` — 組平均數減總平均數,平方後乘該組人數再加總
- **總平方和**:`SST = Σ(X − X̄_T)² = SSb + SSe` — ANOVA 拆解變異的核心等式
- **均方**:`MSb = SSb / (K − 1);MSe = SSe / (N − K)` — 平方和除以各自的自由度
- **Tukey HSD**:`Tukey HSD = (X̄₁ − X̄₂) / s_x̄,s_x̄ = √( MSe / ng )` — 各組人數相同時,每對比較共用同一個標準誤

## 書中例子

**5 歲、8 歲、12 歲孩子對泡泡糖口味冰淇淋的喜好**:三組各 5 人以 1–5 分評分,平均 4.2、3.8、2.4,總平均 3.47。SSe = 10.8、SSb = 8.90,MSe = 0.90、MSb = 4.45,F = 4.94,大於臨界值 3.88。Tukey 值 0.95、4.29、3.33 中只有 5 歲對 12 歲超過 3.77,僅這一對顯著不同。

## 常見誤解

- F 顯著只代表至少有兩組平均數不同,不能直接說每一組都不同,必須做事後比較。
- 三組以上不要用多次 t 檢定取代 ANOVA,型一錯誤機率會隨檢定次數累積。
- Tukey HSD 的標準誤假設各組人數相等;組別人數不等時應改用其他事後比較。
- 統計顯著不等於效果大,還要看 η² 解釋了多少比例的變異。

## 行文表述

以單因子變異數分析比較三個年齡組的喜好程度,組間差異達顯著,F(2, 12) = 4.94, p < .05;Tukey 事後比較顯示僅 5 歲組(M = 4.20)顯著高於 12 歲組(M = 2.40)。

## 臨床比喻(延伸,非書中內容)

比較三種翻身頻率(每 2、3、4 小時)病人的壓傷風險評分時,先用單因子變異數分析看整體是否有差異,顯著後再以 Tukey 找出哪兩種頻率之間不同,而不是直接跑三次 t 檢定。

## 自我檢核

- **Q:為什麼比較三組平均數時,不建議直接做三次獨立樣本 t 檢定?**
  - 每做一次檢定都有機會把其實不存在的差異誤判為顯著,做三次等於讓型一錯誤的機會累積變大;ANOVA 以單一 F 檢定並把組數納入自由度來控制這個問題。
- **Q:計算組間平方和時,為什麼要把每組的離差平方乘上該組人數?**
  - 因為組平均數與總平均數的差距是該組每一個人共同貢獻的,乘上人數才近似反映整組所有成員對組間差異的總貢獻,也才能讓 SSb 與 SSe 相加等於 SST。
- **Q:某研究 F 顯著、η² = .13,而三組中有兩組平均數幾乎相同,該如何解讀?**
  - F 顯著只表示至少一對組別不同,可能是其中一組特別高或低所致;需靠事後比較確認是哪一對,並說明分組約解釋依變項 13% 的變異。
