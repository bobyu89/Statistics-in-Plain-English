# CH09 t 檢定

> t 檢定就是把兩個平均數的差，除以這個差的標準誤，看它是否大到不像巧合。

## 本章在說什麼

本章介紹兩種 t 檢定，兩者都比較兩個平均數，也都靠 t 分布求機率；母體標準差未知且樣本不大時，須用隨樣本數改變形狀的 t 分布。獨立樣本 t 檢定比較兩個互不重疊的組別，關鍵是「平均數差異的標準誤」，即反覆抽樣時兩平均數預期的差距，自由度 n₁ + n₂ − 2，並假設兩組變異數相近。相依（成對）樣本 t 檢定比較同一群人的兩次測量或配對樣本，以每對分數的差值計算標準誤，自由度為配對數減 1。樣本大時小差異也顯著，仍要看原始差距與效應量。

## 什麼是 t 檢定與 t 分布

- 日常說法是比較兩個平均數是否顯著不同；較技術的定義是任何利用 t 分布（Student's t）進行的統計檢定。
- 要用常態分布求精確機率，須知道母體標準差或樣本夠大（n>120）；否則改用依樣本數調整的 t 分布族。
- 獨立樣本 t 檢定需要一個只有兩類的類別自變項，以及一個連續（等距尺度）的依變項。
- 相依樣本 t 檢定用於同一樣本的前後兩次測量，或兩個彼此配對的樣本，例如兒子與其父親的分數。

## 獨立樣本 t 檢定詳解

- 核心問題：兩樣本平均數的觀察差異，相對於單純抽樣就會出現的預期差異（標準誤）而言夠不夠大。
- 兩組人數相近時，差異的標準誤約由兩組各自的平均數標準誤合併而成；人數不等時須按各組貢獻加權調整。
- 檢定假設兩組變異數大致相等；若變異數差很多、人數懸殊或資料非常態，可改用曼-惠特尼 U 檢定。
- 電視節目例子：男 7.5、女 6.5，各 50 人，標準誤 0.40，t=2.50、df=98，雙尾 p 介於 0.01 與 0.02。
- 查表時自由度介於兩列之間就取較小的那列（df=60），這樣比較保守；同例效應量 d=1.0/2.83=0.35。

## 相依（成對）樣本 t 檢定詳解

- 與獨立樣本的差別在於：這裡比較的是同一批人在兩個變項（如休假前、休假後）上的平均數。
- 工廠例子：30 名工人休假前一週平均生產 250 件，休假後一週 300 件，要問這 50 件的差是否顯著。
- 先算每一對分數的差值 D，求這些差值的標準差，再除以配對數的平方根，得到差異的標準誤。
- 自由度是配對數減 1（30 對即 df=29）；父子這類配對樣本的算法相同，只要確保分數正確配對。

## 實例：性別與年級的 GPA 比較

- 獨立樣本：六年級男生 361 人平均 6.58、女生 349 人平均 8.14，差 −1.56，標準誤 0.210，t(708)=−7.45。
- Levene 檢定 F=0.639、p=0.424，兩組變異數無顯著差異，所以讀「變異數相等」那一列的結果。
- SPSS 顯示 p=0.000 不代表機率為零，只是小於 0.001；t 分布對稱，雙尾檢定時負號不影響判斷。
- 相依樣本：689 名學生五年級 GPA 8.08、六年級 7.35，差 0.73，標準誤 0.089，t(688)=8.19，p<0.001。
- 兩個結果都顯著，但作者提醒樣本很大，量表上 0.73 或 1.56 分的差距是否重要，仍要靠效應量與判斷。

## 公式

- **獨立樣本 t 值**:`t = (X̄₁ − X̄₂) / s_(x̄₁−x̄₂)，df = n₁ + n₂ − 2` — 觀察差異除以差異的標準誤
- **差異的標準誤（兩組人數相近）**:`s_(x̄₁−x̄₂) = √( s_x̄₁² + s_x̄₂² )` — 合併兩組各自的平均數標準誤
- **獨立樣本 t 檢定的效應量**:`d = (X̄₁ − X̄₂) / Ŝ，其中 Ŝ = √n₁ × s_(x̄₁−x̄₂)` — 書中例：√50×0.40=2.83，d=0.35
- **相依樣本 t 值**:`t = (X̄ − Ȳ) / s_D̄，df = N − 1` — N 為配對數
- **相依樣本差異的標準誤**:`s_D̄ = s_D / √N` — 差值的標準差除以配對數平方根
- **差值的標準差**:`s_D = √( ( ΣD² − (ΣD)² / N ) / (N − 1) )，D = X − Y` — D 為每一對分數的差

## 書中例子

**Midgley 等人縱貫研究的學生 GPA：男女比較與五、六年級比較**:獨立樣本：六年級男生（n=361, M=6.58）與女生（n=349, M=8.14），Levene 檢定不顯著，t(708)=−7.45、p<0.001，女生較高。相依樣本：689 名學生五年級 GPA 8.08、六年級 7.35，t(688)=8.19、p<0.001，顯著下降。樣本大，仍須評估實務重要性。

## 常見誤解

- 同一群人的前後測要用相依樣本 t 檢定，誤用獨立樣本會算錯標準誤與自由度。
- 獨立樣本 t 檢定假設兩組變異數相近；違反且人數懸殊時要看調整列或改用無母數方法。
- SPSS 的 p=0.000 不是機率為零，應寫成 p<0.001。
- 樣本大時小差異也會顯著，要回頭看原始分數差距與效應量。

## 行文表述

以相依樣本 t 檢定比較學生五年級與六年級的 GPA，差異達顯著，t(688) = 8.19, p < .001；五年級（M = 8.08）高於六年級（M = 7.35）。獨立樣本寫法相同：t(708) = −7.45, p < .001，並附兩組平均數。

## 臨床比喻(延伸,非書中內容)

比較實驗病房與對照病房病人的疼痛分數，用獨立樣本 t 檢定；同一批病人衛教前後的自我照顧分數，則用成對樣本 t 檢定，因為每個人自己就是自己的對照。

## 自我檢核

- **Q:獨立樣本與相依樣本 t 檢定的自由度為何不同？**
  - 獨立樣本有兩組各自估計平均數，自由度為 n₁+n₂−2；相依樣本實際分析的是一組差值，只估計一個平均差，所以是配對數減 1。例如 689 對分數的 df 為 688。
- **Q:「平均數差異的標準誤」為 0.40 是什麼意思？**
  - 表示若母體之間其實沒有差異，反覆隨機各抽 50 人，兩樣本平均數之間平均會相差約 0.40 分。觀察到的差 1.0 是它的 2.5 倍，所以 t=2.50。
- **Q:SPSS 的獨立樣本輸出有「變異數相等」與「不相等」兩列，怎麼選？**
  - 先看 Levene 檢定。p 大於 0.05（如書中 p=0.424）表示兩組變異數無顯著差異，讀相等那一列；若顯著，則讀不相等那一列，其自由度已被調小。
