# CH13 迴歸

> 迴歸把相關變成預測:用預測變項估計依變項,並看每個變項的獨特貢獻。

- 英文:Regression
- 頁數:p.166–184
- 階段:關係與預測 — 兩個變項一起看
- 先備:[[CH08 相關]](從相關到預測)

## 比喻:用身高猜體重

在散布圖上畫一條最貼近所有點的直線。知道一個人的身高,沿著線就能讀出預測的體重;點離線的距離就是猜錯的量。

## 三個重點

1. 簡單迴歸:Ŷ = bX + a,b 是斜率、a 是截距
2. 多元迴歸看的是「控制其他變項後」每個預測變項的獨特貢獻
3. R² 是模型解釋的變異比例;能預測不代表有因果

## 迴歸報表怎麼讀

| 數字 | 告訴你什麼 |
|---|---|
| R² | 模型解釋了依變項多少比例的變異 |
| F 檢定 | 整體模型是否顯著 |
| B(未標準化係數) | X 每增加 1 單位,Y 的預測值改變多少 |
| β(標準化係數) | 比較各預測變項的相對強度 |
| t 與 p | 這個係數是否顯著不為 0 |

## 本章在說什麼

本章從第 8 章的相關與決定係數出發,說明迴歸如何把「兩變項有關」改寫成「已知 X 可預測 Y」。簡單線性迴歸只有一個預測變項,用最小平方法找出讓殘差平方和最小的那條直線,由斜率 b 與截距 a 組成方程式;它提供的資訊其實不比相關係數多。真正的威力在多元迴歸:同時放入多個預測變項,可看整體模型解釋多少變異(R、R²、F 檢定),也能在控制其他變項後檢定每個預測變項的迴歸係數,並用標準化係數 β 比較相對強度。作者以教育年數、工作年資預測月收入,以及預測高中生自我設限策略兩個例子示範,最後提醒迴歸和相關一樣不能證明因果。

## 簡單迴歸與多元迴歸、可用的變項

- 簡單迴歸對應單因子變異數分析:一個預測變項配一個依變項;多元迴歸對應多因子設計,有兩個以上預測變項。
- 相關不區分誰是自變項誰是依變項,迴歸一定要區分,因為目的是用預測變項的已知值去推估依變項。
- 多元迴歸能回答四件事:整體關聯有多強、控制他項後各變項的關係、各變項相對強度、是否有交互作用。
- 依變項須為等距或比率尺度;預測變項可為連續或二分變項。依變項為二分時要用 Logit(邏輯斯)迴歸,本書不談。

## 簡單線性迴歸詳解:方程式、斜率與截距

- 迴歸方程式 Ŷ = bX + a:b 是未標準化迴歸係數(斜率),a 是截距,即 X 為 0 時的預測值。
- 普通最小平方法(OLS)找的是唯一一條讓各資料點到直線距離平方和最小的線,這條線就是迴歸線。
- 斜率等於相關係數乘上兩變項標準差之比,等於把 r 換回原始測量單位;皮爾森 r 則是標準化後的簡單迴歸係數。
- 預測必有誤差:觀察值減預測值就是殘差。正殘差代表低估,負殘差代表高估;相關愈強,預測誤差愈小。
- 含誤差項的方程式寫成 Y = bX + a + e,描述的是實際觀察值而非預測值。

## 多元迴歸:共享變異、R² 與迴歸係數

- 加入第二個預測變項後方程式變成 Ŷ = a + b₁X₁ + b₂X₂,每個係數都是控制其他預測變項後的關係。
- 預測變項彼此相關太高時,各自能解釋的獨特變異所剩無幾,難以分辨個別貢獻,這就是多元共線性問題。
- 輸出分三塊:解釋變異量(R、R²、調整後 R²)、變異數分析(整體模型 F 檢定)、迴歸係數(B、β、t、p)。
- R² 是多元迴歸的效應量;調整後 R² 依預測變項數與樣本數把數值略微下修。
- 未標準化係數 B 單位不同不能互比,要看標準化係數 β;各係數的 t 檢定則檢驗斜率是否顯著不為 0。

## 例子與行文表述:預測自我設限策略

- 464 名高中生,以逃避目標、自我效能、性別(男 = 1、女 = 0 的虛擬編碼)與學業平均成績預測自我設限。
- 整體模型顯著(F = 15.686,p < .001),但只解釋約 12% 的變異(調整後 11.3%),屬中等關聯。
- 成績與自我效能為負向預測,逃避目標為正向預測,性別不顯著;每個結果都是控制其他變項後的淨效果。
- 報告時交代:同時投入哪些預測變項、解釋多少變異、哪些顯著,以及各顯著變項的 β 與方向。

## 總結:迴歸、相關與變異數分析是一家人

- 簡單迴歸的係數只是皮爾森相關係數的未標準化版本,兩者傳達的是同一種關係。
- 迴歸同樣在分割依變項的變異並用自變項解釋,迴歸均方除以殘差均方得到 F,與變異數分析如出一轍。
- 一般說變異數分析用類別自變項、迴歸用連續自變項,但迴歸其實也能處理類別自變項,界線並不絕對。

## 公式

- **簡單迴歸方程式(預測值)**:`Ŷ = bX + a` — b 為斜率,a 為截距
- **迴歸係數(斜率)**:`b = r × ( s_y / s_x )` — 相關係數乘以 Y 與 X 標準差之比
- **截距**:`a = Ȳ − bX̄` — 先算出 b 才能算 a
- **預測誤差(殘差)**:`e = Y − Ŷ = Y − (a + bX)` — 觀察值減預測值
- **含誤差的迴歸方程式(觀察值)**:`Y = bX + a + e` — 描述實際值,把預測誤差算進來
- **兩個預測變項的多元迴歸**:`Ŷ = a + b₁X₁ + b₂X₂` — 每個 b 都是控制另一變項後的係數

## 書中例子

**用教育年數與工作年資預測月收入;再以四個變項預測高中生自我設限**:10 名成人中教育年數與月收入 r = 0.83,得 Ŷ = −3.77 + 0.61X:多讀一年書,預測月收入多 610 美元。加入工作年資後 R = .946、R² = .896,F = 30.095,兩個變項的 β(.676、.485)都顯著。真實資料(n = 464)中,四個變項解釋自我設限約 12% 變異,成績與自我效能負向、逃避目標正向、性別不顯著。

## 常見誤解

- 迴歸建立在相關之上,只能說變項如何相關與預測,不能證明誰造成誰。
- 截距可能落在不合理的值(如月收入 −3.77 千美元),它只是 X = 0 的預測值,不必當真。
- 未標準化係數 B 受測量單位影響,不能直接比大小;比較相對強度要看 β。
- 預測變項彼此高度相關(多元共線性)時,各自的獨特貢獻會被吃掉;樣本太小(如書中示範的 10 人)也不適合跑多元迴歸。

## 行文表述

以多元迴歸檢驗自我設限的預測因子,同時投入逃避目標、學業平均成績、性別與自我效能四個變項,合計解釋 11% 的變異。除性別外皆為顯著預測變項:學業成績(β = −.21)與自我效能(β = −.20)為最強的負向預測因子,逃避目標則為正向預測(β = .13)。

## 臨床比喻(延伸,非書中內容)

想預測病人住院天數,可同時放入年齡、共病數與入院時功能分數。多元迴歸會告訴你三者合起來解釋多少變異,以及控制年齡與共病後,功能分數是否仍有獨立預測力。

## 自我檢核

- **Q:書中說簡單線性迴歸「其實不比相關更有用」,那為什麼還要學它?**
  - 因為它把關係寫成可代入的預測方程式,解讀較直觀(X 每增加一單位 Y 變多少),更重要的是它是理解多元迴歸的基礎,後者才能看控制他項後的獨特貢獻。
- **Q:多元迴歸中,某預測變項的迴歸係數顯著,這句話完整的意思是什麼?**
  - 指在控制(排除)模型中其他預測變項已解釋的變異之後,這個變項與依變項之間仍有顯著關係,也就是它的斜率顯著不為 0,具有獨特解釋力。
- **Q:如果兩個預測變項彼此相關高達 0.90,把兩個都放進模型會發生什麼事?**
  - 它們與依變項重疊的部分大多是共享變異,各自的獨特變異很小,所以第二個變項幾乎不增加解釋力,也難以分辨個別效果,這就是多元共線性。
