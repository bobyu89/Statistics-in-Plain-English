CH 08 · 關鍵術語

相關

相關係數說明兩變項關係的方向與強度，r² 是共享變異比例，但相關不是因果。

比喻 · 冰淇淋與溺水夏天冰淇淋銷量和溺水人數一起上升,但不是冰淇淋害人溺水,是天氣熱同時推高了兩者。相關不等於因果。
皮爾森相關係數（定義式）:r = Σ(z_x · z_y) / N

皮爾森積差相關係數Pearson product-moment correlation coefficient

描述兩個連續變項線性關係方向與強度的統計量 r。

相關不等於因果causation

兩變項一起變動，不代表其中一個造成另一個。

決定係數coefficient of determination

r 的平方，一變項變異可被另一變項解釋的比例。

CH 08 · 再看一張圖

決定係數 r² 是共享的變異

本章主角是皮爾森積差相關係數 r：介於 −1 與 +1，正負號表示方向，絕對值表示強度；它是兩變項 z 分數交乘積的平均，也就是標準化的共變數。作者強調其限制：r 只描述「平均而言」的線性關係，遇到曲線關係或分數範圍被截斷會低估關聯，而且相關不能證明因果，可能有第三變項作用。接著說明用 t 分布檢定 r 是否顯著異於 0（df = N − 2），以及把 r 平方得到決定係數，即兩變項共享的變異比例。最後簡介點二系列、phi 與斯皮爾曼三種特殊相關。

CH 08 · 公式

這一章的公式

皮爾森相關係數（定義式）
r = Σ(z_x · z_y) / N
z 分數交乘積的平均；N 為配對數
相關係數的假設
H₀: ρ = 0 ；H₁: ρ ≠ 0
檢定 r 是否顯著異於 0
相關係數的標準誤
s_r = √( (1 − r²) / (N − 2) )
書中僅供了解，實算用下式
相關係數的 t 檢定
t = (r − ρ) / s_r = r · √( (N − 2) / (1 − r²) )，df = N − 2
虛無假設下 ρ = 0
決定係數
r² = r × r
共享（可解釋）變異的比例
CH 08 · 逐節重點

照書的順序走一遍

01
相關的用途：方向與強度
皮爾森 r 要求兩個變項都是等距或比率尺度的連續變項，且每位受試者的兩個分數必須成對。
02
皮爾森 r 怎麼算、代表什麼
書中採定義式：先把兩變項都轉成 z 分數，逐人相乘得交乘積，加總後除以配對數 N。
03
相關說了什麼、沒說什麼
相關不等於因果：鸛鳥數量與嬰兒出生數同時上升，其實都源自寒冬這個第三變項。
04
顯著性檢定與決定係數
檢定的虛無假設是母體相關 ρ 等於 0，對立假設是 ρ 不等於 0，使用 t 分布，自由度為 N − 2。
CH 08 · 書中例子

高中生學業成績平均（GPA）與 Naglieri 非語文能力測驗的相關

臨床上怎麼想護理人員每月夜班數與疲勞量表分數若 r=0.40，只能說夜班多的人平均較疲勞（共享 16% 變異），不能直接說夜班造成疲勞，年資、家庭照顧負荷都可能是第三變項。

這個例子在做什麼

加州一所高中 314 名十一年級學生的累積 GPA 與 Naglieri 非語文能力測驗分數，r=0.4291、p<0.0001，為中等且顯著的正相關。r²≈0.18，GPA 只解釋測驗分數約 18% 的變異，逾 80% 未被解釋，故作者認為教師評分與標準化測驗測到的是不同構念。

怎麼寫進論文

GPA 與 Naglieri 測驗分數呈中等強度且顯著的正相關，r = .43, p < .001；決定係數 r² = .18，表示測驗分數約 18% 的變異可由 GPA 解釋。（書中指出報告相關時很少附 t 值。）

CH 08 · 常見誤解

這幾個地方最容易想錯

!

顯著的相關不代表因果，可能有第三變項同時影響兩者（鸛鳥與嬰兒、日照與氣溫）。

!

r 只反映直線關係，曲線關係會讓 r 接近 0 而被誤判為無關。

!

天花板或地板效應使分數範圍被截斷，會低估真實的相關強度。

!

強弱門檻只是經驗法則：酒精與肝病的 r=0.15 也可能非常重要。

CH 08 · 自我檢核

先自己答,再點開看答案

Q1
兩變項的 r 接近 0，可以斷定它們沒有關係嗎？
看答案
不行。r 只衡量線性關係，若關係是先升後降的曲線，或其中一個變項的分數範圍被截斷，r 都會很小，卻不代表兩者真的無關，應先看散布圖。
Q2
r = 0.25、N = 100 的相關達顯著，這個關係算強嗎？
看答案
不算強。r² 只有 0.0625，即約 6% 的共享變異；它顯著主要是因為樣本夠大（t=2.56、df=98）。顯著性與關係強度是兩回事。
Q3
為什麼說相關係數是「標準化的共變數」？
看答案
共變數是兩變項離均差交乘積的平均，單位受原始量尺影響；先把兩變項轉成 z 分數再求交乘積平均，就消除了單位，結果被限制在 −1 到 +1，這就是 r。
